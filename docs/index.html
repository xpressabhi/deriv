Architecture

System overview: fixtures fan into chunking and a BM25 index; retrieval feeds the deterministic gate before drafting; the LLM (or the extractive fallback) produces a cited draft; a separate deterministic verifier approves it, sends it to repair, or triggers a documented safe fallback.

Stage flow and gates

Workflow view: policy mode is chosen in code before generation, the verifier runs after generation, failed drafts are repaired and re-verified or replaced by a safe fallback, and every stage leaves auditable artifacts.
